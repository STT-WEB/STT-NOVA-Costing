# STT NOVA-Costing

โปรแกรมดูต้นทุนงานจริงของ Sutee Tankers & Special Truck
**ต้นทุนงาน = จัดซื้อ (NOVA) + ค่าแรงพนักงาน STT (HR) + ผู้รับเหมา** เทียบกับราคาขาย

🔒 เข้าได้ 3 ท่านเท่านั้น: เบียร์ (6100030) · คุณแบล็ค (999999) · คุณประดิษฐ์ (888888)
ใช้ **รหัสพนักงาน + PIN ชุดเดียวกับ NOVA** (แท็บ USERS ใน STT-DB-MASTER)

---

## ขึ้นระบบครั้งแรก — 5 ขั้น (ทำครั้งเดียว)

1. ดับเบิลคลิก **`ติดตั้งเครื่องมือครั้งแรก.bat`** (ถ้าเคยติด clasp ให้ NOVA แล้ว ข้ามได้)
2. ดับเบิลคลิก **`เข้าสู่ระบบ clasp.bat`** → ล็อกอิน `sasipa@suteetankers.com`
3. ดับเบิลคลิก **`สร้างโปรเจกต์ครั้งแรก.bat`** → สร้าง Apps Script โปรเจกต์ใหม่ชื่อ STT NOVA-Costing
4. สร้าง repo ใน GitHub ชื่อ **`STT-NOVA-Costing`** ใต้ `STT-WEB` (แนะนำ Private) → ดับเบิลคลิก **`เชื่อม GitHub.bat`**
5. ดับเบิลคลิก **`อัปเดตระบบ Costing.bat`** → สำรองขึ้น GitHub + อัปโค้ด + เผยแพร่ + ขึ้นลิงก์เว็บให้

> ครั้งแรกที่เปิดเว็บ Google จะขอสิทธิ์ (อ่าน Sheets / Drive / ตั้งเวลา) → กด Allow
> ระบบจะดึงข้อมูลครั้งแรกประมาณ 1–2 นาที แล้วตั้งเวลาอัปเดตเองทุก 10 นาที

**ในเครื่อง = GitHub = Apps Script เหมือนกันทั้ง 3 ที่** (ยกเว้นรหัสลับ clasp และข้อมูลตัวเลขจริง ตาม `.gitignore` แบบเดียวกับ P&S Hub)

## ใช้ประจำวัน

- **แก้โค้ดเสร็จ → ดับเบิลคลิก `อัปเดตระบบ Costing.bat` ครั้งเดียว** (ทดสอบกันพัง → อัปทุกไฟล์ → เผยแพร่)
- **หลักฐานเดียวว่าขึ้นจริง = ป้ายเวอร์ชันบนหัวเว็บเปลี่ยนเลข** (ข้อความ DONE ใน .bat เชื่อไม่ได้)
- ตัวเลขอัปเดตเองทุก 10 นาที · อยากได้เดี๋ยวนี้กดปุ่ม **⟳ อัปเดตตอนนี้**

## ดูตัวอย่างก่อนขึ้นระบบ

เปิด `preview/STT-NOVA-Costing-ตัวอย่าง.html` ด้วย Chrome → ใส่รหัส 6100030 + PIN อะไรก็ได้
(ไฟล์ตัวอย่างใช้ข้อมูลจริง ณ 6 พ.ย. 2569 ของ JT + JM ปี 2569 · รายการจัดซื้อรายบรรทัดมีเฉพาะ JT)

## ถ้ามีปัญหา

| อาการ | แก้ยังไง |
|---|---|
| `clasp push FAILED` | ดับเบิลคลิก `เข้าสู่ระบบ clasp.bat` แล้วรันใหม่ |
| `safety tests FAILED` | ส่งบรรทัดสีแดงให้ Candy |
| ตัวเลขดูแปลก | เปิด Apps Script → รัน `costingSelfTest` → ก๊อป Log ให้ Candy |
| ป้ายเวอร์ชันไม่เปลี่ยน | ปิดแท็บทั้งหมด เปิดใหม่ กด Ctrl+Shift+R |
